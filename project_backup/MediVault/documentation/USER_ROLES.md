# User Roles & Access Control Matrix
## MediCare Role-Based Authorization Specifications

| Role | Default Email | Portal / Views Accessible | Key Capabilities |
| :--- | :--- | :--- | :--- |
| **Admin** | `admin@medivault.com` | Full Administrative Dashboard, All Tabs | Department governance, doctor roster, shift setup, bed allocations, financial summaries, fleet management |
| **Doctor** | `doctor@medivault.com` | Doctor Dashboard, Emergency Ward, Patients | Clinical consultations, diagnoses, prescriptions, urgent lab orders, blood requests, emergency treatment |
| **Nurse** | `nurse@medivault.com` | Staff Portal (Inpatient Roster), Emergency Ward | Emergency registration, clinical triage, priority engine execution, vitals logging, care notes, bed transfers |
| **Receptionist**| `receptionist@medivault.com` | Front Desk, Emergency Registration, Appointments | Patient onboarding, temporary emergency check-in, OPD scheduling |
| **Lab Technician**| `lab@medivault.com` | Laboratory Worklist | Specimen processing, diagnostic report upload, priority worklists |
| **Pharmacist** | `pharmacy@medivault.com` | Pharmacy Management | Dispensing queue, stock adjustments, batch tracking, expiry monitoring |
| **Billing Staff**| `billing@medivault.com` | Billing & Cashier Workspace | Invoice generation, itemized service reconciliation, payment collection |
| **Patient** | `patient@medivault.com` | Patient Self-Service Portal | Booking wizard, viewing lab reports, paying bills, reviewing medical history |
